# Security

Do not disclose vulnerabilities, credentials, API keys, private infrastructure details, or client-sensitive information in a public GitHub issue.

For security-related concerns, contact the LineZero project owner through the established client communication channel. Include:

- affected repository or service
- a concise description of the issue
- reproduction steps when safe to provide
- potential impact
- any known mitigation

If credentials may be exposed, rotate or revoke them immediately and then report the incident.
