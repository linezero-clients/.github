# Contributing

Client repositories in this organization are managed by LineZero and are private by default.

## Workflow

1. Create a short-lived branch from the default branch.
2. Use a descriptive branch name such as `feat/...`, `fix/...`, or `chore/...`.
3. Keep commits focused and avoid committing generated secrets, credentials, or local environment files.
4. Open a pull request describing the change, validation performed, and any deployment impact.
5. Prefer squash merging unless a repository documents a different policy.

## Client boundaries

Do not copy client code, data, credentials, infrastructure details, or proprietary assets between repositories unless the project explicitly requires it and access is authorized.

Repository-specific instructions override these defaults when present.
